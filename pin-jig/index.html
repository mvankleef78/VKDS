    Workflow
    1. Make the pin in MakerWorld image-to-keychain at the same width as here, then print a full plate.
    2. Download Jig STL and print it twice, flat, without supports. The pockets are on top.
    3. Put both jigs in your frame on the small plate: jig 1 on the left, jig 2 on the right, chamfered corner at the back-left.
    4. In xTool Creative Space, import UV layout PNG, then set X 0, Y 0 and width 330 mm (165 mm for one jig). Turn output off for any helper shapes.
    5. Scan the plate to check alignment, nudge if needed, then print with colour + gloss varnish.
